## Landscape

The operator describes servers in a fleet repository and runs them through the
CLI; developers push to their app repositories; the platform server builds and
serves the apps.

## Inside a platform server

Amber marks where app code runs: the build agent, BuildKit and the apps
themselves. Everything else sits on `platform-internal`, a network no app
container joins; Traefik is the only service on both. Only the Jenkins
controller holds the Docker socket, and it runs nothing from an app.

## From a push to a running app

The pipeline is the platform's, loaded from the tag of the kayra version the
fleet pins; the app supplies only data. Images are content-addressed, so a
commit whose inputs did not change builds nothing, and a deploy pulls exactly
the images of the commit it deploys.
